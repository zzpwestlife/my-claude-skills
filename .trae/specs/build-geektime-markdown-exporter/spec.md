# 极客时间专栏 Markdown 导出工具 Spec

## Why
当前缺少一个可稳定复用的自动化导出工具，无法高效将已付费可访问的专栏文章沉淀为可版本管理的本地 Markdown 资产。该能力可提升内容备份、检索与二次整理效率，并降低手工复制的格式损失。

## What Changes
- 新增命令行工具：支持导出单篇文章与批量导出专栏文章。
- 新增登录与会话管理：支持使用已付费账户自动登录并维持有效会话。
- 新增页面解析与内容提取：抽取正文结构并保留标题、段落、代码块、引用等排版。
- 新增图片处理流水线：识别图片、下载到本地、替换为相对路径、支持断点续传与去重。
- 新增 GFM 规范输出：生成符合 GitHub Flavored Markdown 的 `.md` 文件。
- 新增配置系统：支持配置文件与命令行参数覆盖（输出路径、图片目录、命名规则等）。
- 新增健壮性机制：错误分类、重试、详细日志记录与失败清单输出。
- 新增交付物：可执行程序、源代码、使用文档、测试用例，目标运行环境为 macOS。

## Impact
- Affected specs: 文章导出能力、资源下载能力、CLI 交互能力、配置管理能力、日志与容错能力、测试与交付能力。
- Affected code: CLI 入口模块、认证模块、页面抓取模块、DOM/内容解析模块、Markdown 渲染模块、图片下载模块、配置加载模块、日志模块、测试目录、用户文档。

## ADDED Requirements
### Requirement: 账户登录与会话复用
系统 SHALL 提供自动登录能力，仅在用户具备合法已付费访问权限时访问内容，并在批量导出过程中复用会话以减少重复登录。

#### Scenario: 首次登录成功
- **WHEN** 用户提供有效账户凭据并执行导出命令
- **THEN** 系统完成登录并建立可用于后续抓取的会话状态

#### Scenario: 会话过期自动恢复
- **WHEN** 批量导出过程中会话失效
- **THEN** 系统触发重新登录或刷新流程并继续任务，且记录日志

### Requirement: 正文结构化提取
系统 SHALL 从文章页面中提取正文与结构化块元素，并保持原有语义顺序与排版信息。

#### Scenario: 结构保真导出
- **WHEN** 系统解析文章正文
- **THEN** 输出中正确保留标题层级、段落、代码块、引用、列表与换行语义

### Requirement: 图片下载与本地化引用
系统 SHALL 识别正文图片并下载到指定目录，Markdown 中的图片链接需替换为本地相对路径，同时具备断点续传与去重能力。

#### Scenario: 断点续传
- **WHEN** 下载过程中发生网络中断并再次执行导出
- **THEN** 系统从未完成位置继续下载，避免重复传输

#### Scenario: 图片去重
- **WHEN** 多篇文章引用同一图片资源
- **THEN** 系统仅保留一份本地文件并复用引用路径

### Requirement: 标准 Markdown 生成
系统 SHALL 生成符合 GitHub Flavored Markdown 规范的 `.md` 文件，文件名遵循用户配置或默认命名规则。

#### Scenario: 单篇导出
- **WHEN** 用户指定单篇文章链接或文章标识
- **THEN** 系统生成对应单个 `.md` 文件及相关图片资源

#### Scenario: 批量导出
- **WHEN** 用户指定专栏范围进行批量导出
- **THEN** 系统按配置规则生成多篇 `.md` 文件并输出执行摘要

### Requirement: CLI 与配置文件支持
系统 SHALL 提供命令行参数与配置文件双入口，且命令行参数优先级高于配置文件默认值。

#### Scenario: 参数覆盖配置
- **WHEN** 用户在命令行中传入自定义输出目录
- **THEN** 系统以命令行参数作为最终生效值

### Requirement: 错误处理、日志与重试
系统 SHALL 对网络异常、登录失败、解析失败、下载失败等场景进行分类处理，输出可追踪日志并支持可配置重试策略。

#### Scenario: 可观测失败
- **WHEN** 某篇文章解析失败
- **THEN** 系统记录失败原因、上下文与重试结果，并在最终报告中标记失败项

### Requirement: macOS 交付与可验证性
系统 SHALL 提供可在 macOS 运行的可执行程序、源代码、使用文档及自动化测试。

#### Scenario: 本地可执行验证
- **WHEN** 用户按文档在 macOS 环境执行安装与导出命令
- **THEN** 工具可成功运行并通过核心测试用例
